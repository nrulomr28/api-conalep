# API CONALEP

Servicio PHP para consulta de alumnos.

## Endpoints

### Buscar por CURP

GET

/api-conalep/?curp=CURP

### Buscar por Plantel

GET

/api-conalep/?plantel=PLANTEL

### Buscar por Estatus

GET

/api-conalep/?estatus=ESTATUS

### Buscar por Plantel y Estatus

GET

/api-conalep/?plantel=PLANTEL&estatus=ESTATUS
